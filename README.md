# Framepick

**여행 사진을 쉽게 고르고, 영상 속 마음에 드는 순간을 사진으로 남기는 macOS 앱입니다.**

사진 폴더에서 마음에 드는 컷을 셀렉하고, 필요하면 보정한 뒤 AirDrop으로 다른 Apple 기기에 옮길 수 있습니다. 동영상은 프레임 단위로 살펴보며 원하는 장면을 원본 해상도의 PNG/JPEG 이미지로 추출합니다.

## 만든 이유

여행을 다녀오면 사진과 영상이 많이 쌓입니다. 그중 마음에 드는 사진을 쉽게 고르고, 고른 사진만 AirDrop으로 편하게 옮기고 싶어서 Framepick을 만들었습니다.

영상으로 찍어 둔 결과물에서도 사진으로 간직하고 싶은 순간이 있습니다. 그런 장면을 픽셀이 깨지거나 해상도가 줄어드는 걱정 없이 쉽게 꺼내는 것이 또 하나의 목표였습니다. 이를 위해 영상의 실제 프레임을 디코딩하고 원본 해상도로 이미지를 저장하도록 구현했습니다. I-frame과 현재 추출 방식의 관계, 저장 형식에 따른 화질 차이는 아래 [프레임 추출 방식과 화질](#프레임-추출-방식과-화질)에 설명합니다.

직접 사용하는 컴퓨터가 Mac이라 macOS용으로 만들었습니다. 사진을 고르고, 영상에서 필요한 컷을 뽑고, AirDrop으로 공유하는 과정을 한 앱에서 이어가는 데 초점을 맞췄습니다.

## 주요 기능

- **여행 사진 셀렉**: 폴더 열기, 좋아요, 별점, 제외 표시, 검색·필터, 두 장 확대 비교
- **AirDrop 공유**: 좋아요한 사진을 모아 macOS 공유 창에서 전송
- **영상 프레임 추출**: 모든 프레임 탐색, 한 프레임씩 이동, 원본 해상도 PNG/JPEG 저장
- **사진 확인과 보정**: 100% 확대, 회전·자르기, 색상·명암·피부 보정, 프리셋·일괄 보정
- **원본 보존**: 편집 결과를 복사본으로 저장하고 좋아요·보정값을 보관함에 유지
- **선택 기능인 AI 보정 제안**: ChatGPT 연결을 통한 수치 보정값 추천

## 실행

실행은 macOS 14 이상이 필요합니다. 소스에서 빌드할 때는 Xcode 또는 Swift 5.9 이상이 필요합니다. 앱의 사진·동영상 처리에는 외부 패키지를 사용하지 않습니다.

```sh
git clone git@github.com:kicet3/vedio_selector.git
cd vedio_selector
./scripts/build-app.sh
open dist/Framepick.app
```

SSH를 사용하지 않는다면 `git clone https://github.com/kicet3/vedio_selector.git`으로 내려받을 수 있습니다.

`dist/Framepick.app`을 더블클릭하거나 응용 프로그램 폴더로 옮겨 실행할 수 있습니다. 빌드는 현재 Mac의 아키텍처로 생성되며 로컬 실행용 임시 서명을 적용합니다. 다른 Mac에 배포하기 위한 Developer ID 서명·공증은 별도입니다.

사진 선별·편집·프레임 추출은 Mac에서 로컬로 처리하며 ChatGPT 로그인이 필요하지 않습니다. AI 보정 제안을 사용할 때만 별도 Codex CLI와 로그인이 필요합니다.

## 빠르게 사용하기

1. 여행 사진과 영상이 담긴 **폴더 열기** (`⌘O`).
2. 사진을 크게 확인하고 마음에 드는 컷에 **좋아요** (`L`) 표시.
3. 영상은 방향키로 원하는 프레임을 찾고 **사진 추출** (`⌘E`). `L`을 누르면 추출과 좋아요를 함께 처리합니다.
4. 왼쪽 **좋아요**에서 사진을 모아 확인하고 **AirDrop**으로 전송하거나 **폴더에 저장**.

## 사진 고르기

1. **폴더 열기** (`⌘O`)로 사진이 있는 폴더를 선택합니다. 하위 폴더 포함 여부를 선택할 수 있습니다. 폴더를 앱으로 드래그해도 됩니다.
2. 사진을 클릭하면 크게 열립니다. 썸네일 왼쪽 위 선택 버튼 또는 `⌘/⇧클릭`으로 여러 장을 선택합니다. 하트 또는 `L`로 좋아요를 변경합니다.
3. **좋아요만**은 현재 폴더를 필터링합니다. 왼쪽 **좋아요**는 모든 폴더의 좋아요를 모아 보여줍니다.
4. **폴더에 저장**으로 선택한 사진을 복사합니다. 선택이 없으면 현재 보이는 사진을 저장합니다.
5. **AirDrop**은 현재 목록에서 좋아요한 사진만 보냅니다. 여러 장을 선택했다면 그중 좋아요한 사진만 보냅니다. 받는 기기는 macOS AirDrop 창에서 선택합니다.

폴더의 원본 사진은 복사하지 않고 직접 참조합니다. 최근 폴더와 좋아요는 앱을 종료해도 유지됩니다. 폴더 새로고침은 새 파일을 반영하고 중복 추가를 방지합니다. 폴더가 이동되거나 외장 디스크가 분리된 경우 다시 연결해 열어 주세요.

별점 **0–5** (`Control+0…5`)과 제외 표시 (`X`)로 후보를 정리하고, 최소 별점·제외 여부·이름 검색·좋아요 필터를 함께 사용할 수 있습니다. 제외 표시는 파일을 삭제하지 않습니다. 두 장을 선택한 뒤 **두 장 비교** (`⇧⌘C`)를 누르면 각각 확대해 확인할 수 있습니다.

## 확대와 편집

- 사진을 한 번 클릭하면 팝업 없이 중앙에 원본 해상도로 크게 표시하고 오른쪽에 세로 사진 목록을 보여줍니다. 목록 클릭이나 `←` / `→`로 이동하고 `Esc` 또는 그리드 버튼으로 전체 사진으로 돌아갑니다.
- **트랙패드 핀치**, **⌘ + 마우스 휠**, **확대·축소 버튼**으로 배율을 바꿉니다.
- **100%**는 사진 1픽셀을 화면 1픽셀에 대응시킵니다. **화면 맞춤**은 전체 사진이 보이도록 조절합니다.
- 확대한 사진은 드래그나 두 손가락 스크롤로 이동합니다. 더블클릭은 확대/맞춤 전환입니다. 사진 영역을 클릭한 뒤 `+`, `-`, `0`(맞춤), `1`(100%)도 사용할 수 있습니다.
- 오른쪽 패널의 **편집**, 도구막대의 편집 아이콘, 또는 우클릭 **사진 편집**으로 편집기를 엽니다.
- 좌우 90도 회전, 수평 맞추기, 드래그·비율 자르기를 지원합니다. 자르기 중에는 `⌥드래그`로 화면을 이동합니다.
- 노출(-4~+4 EV), 대비, 밝은/어두운 영역, 블랙 포인트, 색온도·틴트, 채도·생동감, 3구간 톤 커브, 선명도, 노이즈 감소, 비네트, 자동 색상 보정을 제공합니다.
- RGB 히스토그램과 암부·명부 클리핑 비율, **보정 전** 비교, **실행 취소/다시 실행** (`⌘Z` / `⇧⌘Z`)를 제공합니다.
- 기본 프리셋 5종과 사용자 프리셋 저장·삭제를 지원합니다. **보정값 복사** 후 사진 목록의 **선택 사진 작업 → 복사한 보정 적용**으로 일괄 보정할 수 있습니다. 색상·얼굴 설정만 복사하며 각 대상의 기존 자르기·회전은 유지합니다. 일괄 출력은 JPEG 복사본이며 중단할 수 있습니다.
- **복사본 저장**은 PNG/JPEG 편집본을 보관함에 추가합니다. 원본은 변경하지 않습니다. 편집본을 실제 폴더에 두려면 **폴더에 저장**을 사용합니다.

편집한 복사본에는 보정값과 원본 연결을 저장합니다. 다시 편집할 때 원본에서 보정을 재구성하므로 노출·회전이 누적되지 않습니다. 폴더 원본이 이동되었다면 재편집을 위해 해당 원본을 다시 연결해야 합니다.

## 얼굴 보정

편집기의 **얼굴 보정**에서 피부 매끄러움·얼굴 밝기·피부 톤의 따뜻함을 조절합니다. Apple Vision으로 얼굴과 주요 부위를 이 Mac에서 감지하며 감지된 모든 얼굴에 동일한 강도를 적용합니다. 눈·눈썹·코·입 주변을 보호하고 얼굴 영역의 경계를 부드럽게 처리합니다. 얼굴이 감지되지 않으면 조절기가 비활성화됩니다.

이 기능은 피부 영역의 질감·빛·색 보정입니다. 얼굴형 변형, 잡티별 제거 브러시, 생성형 얼굴 복원 기능은 포함하지 않습니다. 얼굴 감지는 옆모습·가려짐·작은 얼굴에서 실패할 수 있습니다.

## ChatGPT AI 보정 제안

1. **Framepick → ChatGPT AI 설정…** (`⌘,`) 또는 편집기의 AI 설정을 엽니다.
2. 공식 Codex CLI가 설치되어 있어야 합니다. 자동으로 찾지 못하면 **실행 파일 선택**으로 지정합니다.
3. **ChatGPT로 로그인**을 눌러 공식 브라우저 OAuth를 완료합니다. Framepick 전용 로그인이며 기존 Codex 로그인과 별개입니다.
4. 편집기에서 원하는 보정 방향을 적고 **이 사진 분석**을 누릅니다. 선택한 원본의 축소본(최대 1,600px, GPS·EXIF 제거)과 요청 내용만 OpenAI로 전송합니다.
5. 설명을 읽고 **제안 적용**을 누릅니다. 원본 해상도로 로컬 보정을 적용하며 실행 취소가 가능합니다.

ChatGPT 계정의 Codex 이용 권한과 사용 한도가 적용됩니다. 이 연결은 숫자 보정값을 추천하며 생성형 이미지 편집·Photoshop 전체 기능을 제공하지 않습니다. [공식 인증 근거와 구현·검증 범위](docs/AI-INTEGRATION.md), [유사 앱 조사](docs/COMPETITOR-RESEARCH.md).

## 동영상에서 사진 추출

폴더 안의 동영상을 선택하거나 **파일 추가** (`⇧⌘O`)로 엽니다.

| 조작 | 기능 |
| --- | --- |
| `←` / `→` | 정확히 한 프레임 이동 |
| `⇧←` / `⇧→` | 10프레임 이동 |
| Space | 재생 / 일시정지 |
| 프레임 번호 입력 후 Enter | 원하는 프레임으로 바로 이동 |
| 오른쪽 프레임 리스트 | 모든 프레임을 120장씩 페이지로 탐색, 한 열 / 두 열 전환 |
| 회전 버튼 | 화면을 좌우 90도 회전 |
| `⌘E` | 현재 방향 그대로 원본 크기 PNG/JPEG 사진 추출 |
| `L` | 현재 프레임을 추출하고 좋아요 표시 / 취소 |

동영상 뷰어는 세로 공간 전체를 사용하고 프레임 리스트는 오른쪽에 표시됩니다. 두 영역 사이의 경계를 드래그하면 목록 너비를 조절할 수 있습니다. 재생 컨트롤은 뷰어 하단에 겹쳐 표시됩니다.

정지한 동영상 프레임에도 사진과 동일한 확대·이동 기능을 제공합니다. **세로 맞춤**은 이미지가 뷰어 높이를 채우게 하며, 가로로 넘치는 부분은 드래그해 볼 수 있습니다. 같은 영상의 프레임을 이동할 때 확대 위치를 유지합니다. 회전 설정은 영상별로 기억하며, 원본 동영상 파일은 변경하지 않습니다.

프레임 목록은 FPS로 추정하지 않고 AVAssetReader가 반환한 실제 표시 시각을 정렬해서 생성합니다. 가변 프레임 영상과 B-frame을 처리하며, 프레임 간격을 띄워 샘플링하지 않습니다. 썸네일은 필요한 만큼만 생성하고 메모리 캐시를 제한합니다.

### 프레임 추출 방식과 화질

I-frame 기반 추출로 기대하는 핵심인 **영상 데이터에서 직접 이미지를 얻는 것**을 구현했습니다. 현재 버전은 I-frame만 골라 추출하지 않고, AVFoundation을 통해 전체 프레임을 탐색하며 선택한 시각의 프레임을 디코딩합니다. 저장할 때는 축소된 썸네일이나 화면 캡처 대신 원본 해상도의 프레임을 사용합니다.

- **PNG**: 디코딩된 이미지를 무손실로 저장해 저장 과정의 추가 손실 압축을 피합니다.
- **JPEG**: 원본 픽셀 크기를 유지하며 품질 0.96으로 저장합니다. 손실 압축이 적용됩니다.
- 원본 영상에 이미 있는 압축 흔적이나 움직임에 의한 흐림을 복원하는 기능은 아닙니다. 결과물의 선명도는 촬영 영상의 해상도와 품질에 영향을 받습니다.

## 보관 위치와 지원 범위

- `~/Library/Application Support/Framepick/library.json`: 최근 폴더·영상, 사진 목록, 좋아요·별점·제외·보정값
- 같은 위치의 `presets.json`: 사용자 보정 프리셋
- 같은 위치의 `AI/`: Codex가 관리하는 Framepick 전용 인증·설정
- 같은 위치의 `Photos/`: 파일로 추가한 사진, 추출 사진, 편집한 복사본
- 폴더에서 연 원본은 기존 위치에 남습니다. 원본 사진 삭제 기능은 없습니다.
- 영상은 AVFoundation이 읽을 수 있는 코덱, 사진은 ImageIO가 읽을 수 있는 형식을 지원합니다. 일반적인 MOV/MP4 및 JPEG/PNG/HEIC를 사용할 수 있습니다. 편집·추출 출력은 정지 이미지이며 Live Photo의 동작, HDR·RAW 현상 정보 전체를 보존하는 편집기는 아닙니다.

## 개발 및 검증

```sh
swift run Framepick
swift test
```

테스트는 실제 H.264 영상의 전체 프레임 수·시간·색상·회전·추출 크기, 사진 선별 상태 영속화, 보정 픽셀·얼굴 보호 마스크, 원본 보존·재편집·일괄 처리, 확대·이동, AI 프로토콜·취소·전송본 메타데이터 제거를 검사합니다. 공개 인물 사진의 로컬 얼굴 감지와 실제 앱의 보정·확대·저장·비교 화면도 확인했습니다. AirDrop 실제 기기 수신과 ChatGPT OAuth 완료 후 온라인 분석은 아직 검증하지 않았습니다.

개발용 `FRAMEPICK_LIBRARY_PATH` 환경변수로 테스트 보관함을 분리할 수 있습니다. `--import <파일 또는 폴더>`로 미디어를 열 수 있습니다. `--render-preview`는 앱 자신의 화면만 PNG로 렌더링하며 `FRAMEPICK_PREVIEW_PATH`로 저장 경로를 지정합니다.

## 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `Sources/Framepick/` | SwiftUI/AppKit 화면, 사진 선별·편집 흐름, AirDrop, AI 연결 |
| `Sources/FramepickCore/` | AVFoundation 프레임 처리, 폴더·보관함, Core Image 보정, Vision 얼굴 감지 |
| `Tests/FramepickCoreTests/` | 미디어 처리·선별·편집·AI 연결 자동 테스트와 테스트 영상 |

| `scripts/` | 앱 번들 빌드와 아이콘 생성 |
| `docs/` | 구현 기록과 기능 조사 문서 |
