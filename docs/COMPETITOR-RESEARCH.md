## 이번 선별 기능의 사용 흐름

1. 폴더를 연 뒤 각 썸네일의 왼쪽 위 선택 버튼 또는 ⌘/⇧ 클릭으로 사진을 고른다. 사진 본문을 클릭하면 기존처럼 세로 공간을 사용하는 큰 뷰어로 열린다.
2. 썸네일 아래 별점을 클릭하거나 `선택 사진 작업` 메뉴로 여러 장에 별점·제외 표시를 지정한다. 같은 별점을 다시 누르면 0점으로 해제된다.
3. `모든 별점`, `제외 표시 포함`, 정렬 메뉴를 조합해 후보를 좁힌다. 폴더·검색·좋아요 조건과 함께 적용된다.
4. 두 장을 고르고 `두 장 비교`를 누른다. 각각 전체 해상도로 확대·이동하며 별점, 좋아요, 제외 여부를 변경한다. 비교 중 제외 표시를 해도 해당 사진을 계속 볼 수 있다.
5. 편집에서 복사한 보정은 `선택 사진 작업 → 복사한 보정 적용`으로 적용한다. 여러 사진마다 구도가 다르므로 잘라내기와 회전은 일괄 복사 대상에서 제외한다.

제외는 원본 파일 삭제가 아닌 보관함의 상태 표시다. 기본 보기에는 제외 사진도 표시하며, 사용자가 `제외 숨기기`를 선택해 감춘다. 기존 보관함은 새 별점·제외 필드가 없어도 읽을 수 있다. 두 장 비교는 각각 확대하는 방식이며 확대 위치를 동기화하지 않는다.

## 얼굴 보정 검증과 제약

얼굴 보정은 이 Mac에서 검출한 얼굴 좌표와 랜드마크로 국소 마스크를 만들어 처리한다. 얼굴형 변형, 눈 크기 변경, 생성형 피부 재구성, 특정 인물의 신원 식별은 제공하지 않는다. 작은 얼굴, 옆모습, 가려진 얼굴은 검출이 누락될 수 있으며, 검출된 모든 얼굴에 같은 보정값을 적용한다. 배경 전체에 피부 보정을 적용하는 방식이 아니지만 실제 피부 분할 모델은 아니므로 강한 보정에서는 머리카락이나 경계의 결과를 확대해 확인하는 것이 좋다.

2026-09-22에는 [scikit-image 공식 저장소의 astronaut.png(v0.25.2)](https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/astronaut.png)를 임시 폴더에 내려받아 실제 인물 입력으로 검증했다. [공식 데이터 문서](https://scikit-image.org/docs/0.25.x/api/skimage.data.html#skimage.data.astronaut)는 NASA 원본을 바탕으로 한 public-domain 샘플이라고 설명한다. 샘플은 저장소나 앱 배포물에 추가하지 않았다.

- `ImageEditor.faces`에서 얼굴 1개와 양쪽 눈 랜드마크 각 6점을 검출했다.
- 피부 부드럽게 0.75, 얼굴 밝기 0.35, 피부 온기 0.25를 적용해 512×512 원본 크기와 256×256 미리보기 렌더링에 성공했다.
- 보정 전후 RGB 차이의 합이 3을 넘는 픽셀은 4,269개였고, 검출 얼굴 영역 밖에서는 해당 변화가 없었다. 원본 PNG 바이트는 동일했다.
- 실행은 약 0.68초였으며 해당 Mac에서의 단일 샘플 측정값이다. 다양한 인물·피부색·조명·해상도에 대한 품질 보장을 의미하지 않는다.
- 전체 검증은 로컬 Vision/Core Image 경로만 사용했으며 외부 AI에 사진을 전송하지 않았다.

## 다음 확장 후보

- 유사 프레임 묶기, 자동 선명도 점수, 눈 감김 후보 표시는 대량 프레임 선별에서 효용이 높다. 신뢰도와 수동 수정 UI를 함께 설계해야 한다.
- XMP 별점 읽기·쓰기는 다른 사진 편집기와 함께 사용하는 워크플로에 필요하다.
- 히스토그램과 암부·중간톤·명부 톤 커브는 구현했다. 클리핑 경고, 자유 곡선·채널별 커브, 사용자 마스크, 얼룩 제거, 전문 RAW 현상은 더 정밀한 편집을 위한 후속 작업이다.
- GPT 연동의 인증·요금·사진 전송 범위와 지원 경로는 [OpenAI 통합 조사](AI-INTEGRATION.md)를 따른다. ChatGPT 구독이나 Codex 로그인이 곧바로 제삼자 앱의 이미지 API 권한을 제공한다고 가정하지 않는다.
