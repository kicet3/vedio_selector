# Framepick 구현 기록

## 목표
macOS 14 이상에서 동영상의 실제 프레임을 탐색·추출하고, 가져온 사진과 추출한 사진의 좋아요를 저장하며 AirDrop으로 전달한다.

## 디자인
- 색상: sidebar #172538, canvas #17212D, surface #F5F7FA, white #FFFFFF, accent #3678D3, like #C95072.
- 서체: macOS 시스템 서체. 타임코드와 프레임 번호에만 고정폭 숫자 사용.
- 구성: 왼쪽 보관함 / 세로 공간을 채우는 프레임 뷰어 / 오른쪽 프레임 리스트. 재생 컨트롤은 뷰어 하단 오버레이. 사진은 크기 조절 가능한 그리드.
- 사진의 색과 구도를 방해하지 않는 화면. 빈 상태에는 가져오기와 실제 사용 흐름을 표시.

- [x] 사진 회전·자르기·밝기 조절, 원본을 보존하는 복사본 저장

- [x] 동영상 화면 회전, 회전한 사진 추출, 영상별 방향 기억
- [x] SwiftUI 작업 화면, 키보드 탐색, AirDrop 연결

## 주요 선택
외부 패키지 없이 SwiftUI, AppKit, AVFoundation, ImageIO를 사용한다.
압축 샘플의 실제 presentation timestamp를 수집하고 표시 순서로 정렬한다. FPS × 길이 추정이나 간격 샘플링으로 프레임을 누락하지 않는다.
사진 상세 목록과 프레임 목록은 처음에 120개를 표시하고, 맨 아래까지 스크롤하면 다음 120개를 이어 붙인다. 이전 항목을 유지해 위로 다시 탐색할 수 있으며, 키보드나 번호 입력으로 이동한 항목도 자동으로 표시 범위에 포함한다. LazyVGrid로 화면 주변의 썸네일만 생성하고, 화면을 벗어난 썸네일은 뷰에서 해제하며 렌더러 캐시는 크기를 제한한다.
폴더로 연 사진과 동영상은 원본을 참조한다. 파일로 추가한 사진과 추출·편집한 사진은 앱 보관함에 보관한다. 원본 파일 삭제 기능은 제공하지 않는다.
확대는 NSScrollView의 magnification과 중앙 정렬 NSClipView를 사용한다. 화면 크기만 늘리는 방식은 제거했다. Retina에서 100%는 실제 픽셀 대응이며 동영상의 인접 프레임 탐색에서는 확대 위치를 유지한다.
폴더 열기·좋아요 필터·편집·프레임 탐색은 구현 및 테스트했다. AirDrop 수신 기기로의 실제 전송, 개발자 서명·공증은 수행하지 않았다.

## 사진 선별·고급 보정 확장 (2026-09-22)

- 별점·제외·복합 필터·정렬, 두 장 확대 비교, 일괄 보정과 중단을 추가했다.
- Core Image에서 노출·명암·색상·톤 커브·디테일·수평 맞춤을 적용한다. 원본 캐시는 실제 디코딩 비용 기준 최대 192 MiB이며 파일 변경 시 무효화한다.
- Vision으로 얼굴과 랜드마크를 검출하고, 경계가 부드러운 얼굴 마스크에서 피부 매끄러움·밝기·온기를 조절한다. 눈·눈썹·코·입은 보호한다. 생성형 얼굴 복원이나 얼굴형 변형은 구현하지 않았다.
- 편집 세션은 실행 취소·다시 실행, 같은 구도의 보정 전 비교, RGB 히스토그램, 기본·사용자 프리셋을 제공한다. 저장된 레시피는 원본에서 재구성해 중복 보정을 방지한다. 일괄 보정은 각 대상의 기존 구도를 유지한다.
- ChatGPT 연결은 공식 Codex app-server OAuth를 사용한다. 축소·메타데이터 제거 사진의 수치 보정 제안을 검증해 사용자가 적용한다. 세부 사항은 [AI 통합 문서](AI-INTEGRATION.md), 선정 근거는 [경쟁 앱 조사](COMPETITOR-RESEARCH.md)에 기록했다.

### 검증 결과

`swift test`: 57개 통과. 실제 프레임 처리, 폴더/선별 상태 영속화, 픽셀 보정, 얼굴 보호 마스크, 레시피 재편집, 일괄 보정의 원본·구도 보존, 네이티브 확대, AI 프로토콜·취소·메타데이터 제거를 포함한다.

격리된 테스트 앱과 보관함에서 실제 화면의 얼굴 감지, 피부·밝기 슬라이더, 확대·100%, 보정 전 비교, 실행 취소, 복사본 저장, 두 장 비교, AI 설정의 CLI 탐지를 확인했다. 공개 NASA 인물 샘플에서 얼굴 1개·양쪽 눈 랜드마크를 감지했고, 512px 보정·256px 미리보기 및 원본 보존을 검증했다. 이 샘플은 AI에 전송하지 않았다.

실제 ChatGPT OAuth 로그인 완료 후 온라인 분석, 실제 AirDrop 수신, Developer ID 서명·공증은 검증/수행하지 않았다. 로컬 앱은 현재 Mac 아키텍처의 임시 서명 빌드다. Photoshop의 레이어·선택 브러시·생성형 채우기·전문 RAW 현상 기능 전체는 포함하지 않는다.

## 연속 스크롤 탐색 (2026-09-23)

- 사진 상세 보기와 영상 프레임 목록에서 이전·다음 페이지 버튼을 제거하고 하단 도달 시 자동으로 다음 항목을 이어 붙인다. 사진 전체 그리드는 기존 연속 스크롤을 유지한다.
- 목록 확장 시 현재 선택과 스크롤 위치를 유지한다. 검색·정렬 결과가 바뀌면 목록 범위를 재설정하고, 선택 항목이 처음 표시 범위를 벗어나도 해당 위치로 이동한다.
- `swift test`: 60개 통과. 추가한 3개 테스트는 실제 NSHostingView/NSScrollView에서 한 열·두 열의 하단 자동 로딩, 마지막 홀수 항목, 이전 항목으로 복귀, 최초 선택·번호 이동·경계 이동, 필터 변경·빈 목록을 검증한다.
